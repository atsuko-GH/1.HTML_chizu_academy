(3)工夫した点・こだわった点
・後で見直しやすいよう、ソースコードに日本語のコメントを多く残すことを意識した（特にCSS）。
こんな感じ↓
  background-size: cover;       /* 画像をすき間なく敷きつめる */
  background-position: center;  /* 画像の真ん中を中心に表示する */
  max-width: 100%;  /* 画面が狭いときは、画面の幅より大きくならない */・PC、スマホどちらで見ても崩れないよう、CSSで「@media」を使う＆すべての画像に「max-width: 100%」を記載。
・遷移先ページのhtmlファイルを、メインページのhtmlファイルと同じフォルダ内に作り、1つのCSSファイルを共通で使えるようにした。

(4)難しかった点

・AIのサポートがないと、絶対作れない。数年前までのエンジニアすごすぎ・・！
